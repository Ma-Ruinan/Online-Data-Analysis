# 线上真实数据测评集构建

把周期性收集的Markdown、Excel用户记录与报错材料，提炼成有代表性、来源可追溯、可一次提交执行的智能体测评数据集。

这是一个可从GitHub安装的Codex skill。它固化了材料理解、去噪、需求合并、选题归类、执行前规划、素材构造、自然题面、少量正式交付，以及进入Rubric设计前的整体检查。默认约30题，按有效素材调整，不凑数或强求完全覆盖。

## 安装

在支持GitHub技能安装的Codex对话中直接说：

> 请使用 skill-installer，从 https://github.com/Ma-Ruinan/Online-Data-Analysis 安装 skills/online-data-eval-dataset 这个 skill。

需要固定版本时，可指定Git引用`v1.0.0`。安装完成后下一轮对话即可调用。其他设备按相同方式安装。

仓库的[技能目录](skills/online-data-eval-dataset/SKILL.md)是安装源；[dist](dist/)保存版本包及SHA256。`.skill`包是带技能根目录的ZIP归档，用于下载、校验和归档；安装优先使用上面的GitHub路径，不假设所有客户端都支持直接导入该扩展名。

## 调用

完整构建时可以说：

> 请使用 $online-data-eval-dataset。原始材料在“我的本批日志目录”，包括Markdown和Excel。请从中提炼约30个典型任务，制作完整数据集并核查，保存到“我的输出目录”。沿用技能中的题面、来源追溯和交付规范，暂不设计Rubric。

只分析或规划时说：

> 请使用 $online-data-eval-dataset，先理解本批线上材料，说明哪些值得提炼、哪些需要排除，并给出类别、题量和逐题规划，暂不制作附件。

已有数据集时说：

> 请使用 $online-data-eval-dataset，全面检查这版数据集的题面、全部素材、数据口径与来源关系，只输出检查结论，不修改文件。

技能会尊重这类阶段限制。构建模式下会继续做到制作与核查，无需每个阶段重复确认。任务要求、题量、分类和保存路径都可用自然语言覆盖默认设置。

## 生成结果

每题独立目录，`问题描述.txt`可直接粘贴进聊天框，输入素材在同一目录，拖入即可提交。没有素材子文件夹或输入压缩包。正式交付采用如`C01_考核通报更新.docx`的唯一名称，多份输入通常汇总为一个主文件。

根目录保留数据集说明、题目索引、来源与调整说明、文件哈希清单。原文与整理、补充、构造分开记录，制作说明不进入受测题面或素材。默认不纳入需要图片或音视频理解的任务，不恢复不可取得的隐含记忆。单独的工具报错不自动变成一道试题。

这些规范服务于当前工作方式，可按明确的新要求调整。技能不自动执行真实业务、给他人发消息、公开日志或发布生成的数据集；也不自动设计Rubric或评分。

## 维护与版本包

技能的Python辅助脚本仅依赖Python 3.10+标准库。Office文件和PDF的实际制作、渲染需要运行环境的文档、表格或课件能力，技能会按当前工具处理，不绑定某台电脑的绝对路径。

```text
python -m unittest discover -s tests -v
python skills/online-data-eval-dataset/scripts/package_skill.py skills/online-data-eval-dataset --version 1.0.0 --output dist
```

更新技能时修改`VERSION`和技能元数据版本，运行测试，重新生成版本包并提交。每个包提供SHA256，版本分支用于按版安装，提交SHA可精确固定源码。辅助检查只验证能够机械验证的部分，完整业务质量仍需逐题内容复核。

仓库仅包含通用技能、模板、独立构造的测试样例和版本包，不附带实际线上日志或本轮业务数据集。
